# Before public release

- [ ] Confirm final study title, complete author list, venue/year and citation.
- [ ] Approve a license for project-authored code and research data/documents.
      MIT for code and CC BY 4.0 for text/data are template suggestions, not
      licenses automatically applied by this package.
- [ ] Review third-party notices and Spring PetClinic's Apache-2.0 attribution.
- [ ] Review hostnames, local paths and logs in the preserved research artifacts.
- [ ] Resolve/document the dirty historical source provenance and mutable Docker
      image limitation; do not claim exact historical execution reproduction.
- [ ] Review statistical design/assumptions and interpretation with all authors.
- [ ] Record the validation environment and run archive/source checks.
- [ ] Test a fresh install and supported-hardware pilot in an isolated database.
- [ ] Review repository size; consider a versioned DOI-bearing archive (e.g.
      Zenodo) for the release, retaining checksums if large data moves elsewhere.
- [ ] Tag a reviewed release and archive it; add the real DOI/citation afterward.

No commit, push, repository rename or public release is performed by packaging.
